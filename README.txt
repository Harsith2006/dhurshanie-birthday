BIRTHDAY SURPRISE PAGE - DEPLOY FOLDER
========================================

HOW TO DEPLOY (Netlify - FREE, 5 minutes):
1. Go to https://app.netlify.com/drop in your browser
2. Drag the ENTIRE "birthday-deploy" folder onto the page
3. Netlify gives you a live URL like: https://amazing-cupcake-123456.netlify.app
4. Share that link via WhatsApp/Instagram  🎉

HOW TO EDIT LETTER BEFORE DEPLOYING:
1. Open index.html in Notepad (right-click > Open With > Notepad)
2. Press Ctrl+F and search for:   letter:'Dear Dhurshanie
3. Edit the text between the quotes  (use \n for newline, \n\n for paragraph)
4. Save, then drag-drop to Netlify

FILES IN THIS FOLDER:
  index.html              - The full birthday page (everything is here)
  assets/photos/          - 9 photos (photo1.jpg ... photo9.jpg)
  assets/video/           - Opening video (opening.mp4)
  assets/audio/           - Song (song.mp3)
  netlify.toml            - Netlify cache settings (don't delete)

IMPORTANT: Upload ALL files + folders together, not just index.html!
